TECHNISCHES PRINZIP
- Eine gemeinsame Startseite: index.html
- Alle Fachmodule liegen flach im selben Verzeichnis.
- Jedes Modul behält seinen eigenen lokalen Speicher-Schlüssel bzw. seine eigene IndexedDB.
- Es gibt KEINE gemeinsame Fachdatenbank.
- Eine gemeinsame Service-Worker-Datei stellt die Programmdateien offline bereit.
- Browser-/Websitedaten löschen kann die lokalen Fachdaten aller Module dieser Webadresse löschen. Deshalb die Sicherungsfunktionen der jeweiligen Module verwenden.

WICHTIG ZU VERKEHRSSICHERHEIT / QR
Die vorhandenen QR-PNG-Dateien wurden aus der hochgeladenen Version übernommen. Einige enthalten die bisherige GitHub-Webadresse. Wenn die neue Arbeitszentrale unter einer anderen URL veröffentlicht wird, die gedruckten QR-Codes prüfen bzw. neu erzeugen.
