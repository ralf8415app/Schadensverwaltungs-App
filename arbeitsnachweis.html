App-Anleitung – Arbeitsnachweis / Rapport

1. App öffnen und verwenden

Die App kann im Browser auf iPad, iPhone oder Windows verwendet werden. Für den ersten Aufruf und für Updates muss die Seite erreichbar sein. Bereits geladene App-Dateien werden für die Offline-Nutzung zwischengespeichert.

Auf unterstützten Geräten kann die Seite über das Browser-Menü zum Home-Bildschirm hinzugefügt werden. Alternativ kann sie als Favorit/Lesezeichen geöffnet werden.

2. Neue Woche anlegen

Oben die Kalenderwoche, das Jahr und den Mitarbeiternamen eintragen. Über Neu wird ein leeres Formular für eine neue Woche erstellt.

3. Tätigkeiten und Stunden erfassen

Für Montag bis Freitag stehen eigene Bereiche zur Verfügung. Pro Zeile werden Tätigkeit, Objekt / Einsatzort und Stunden eingetragen. Über + Zeile können beliebig weitere Einträge ergänzt werden. Mit dem roten Papierkorb wird eine Zeile entfernt.

Die App prüft keine Mindest- oder Sollstunden. Sie addiert ausschließlich die eingegebenen Stunden. Unter jedem Tag wird die Tagessumme angezeigt; oben wird die gesamte erfasste Wochenzeit zusammengezählt.

5. Speichern und später weiterbearbeiten

Mit Speichern wird der aktuelle Rapport lokal im Browser dieses Geräts gespeichert. Gespeicherte Rapporte erscheinen unten in der Liste und können mit Laden wieder geöffnet oder mit Löschen entfernt werden.

Wichtig: Werden Browser-/Website-Daten gelöscht oder der Browser vollständig zurückgesetzt, können lokal gespeicherte Rapporte verloren gehen.

6. Vorschau, PDF, Drucken und Teilen

Über Als PDF / Vorschau wird eine übersichtliche Ausgabe erzeugt, die sich am Eingabeformular orientiert. Über Drucken / Teilen kann die System-Druckfunktion geöffnet werden. Dort kann – je nach Gerät – gedruckt, als PDF gesichert oder über die Freigabefunktion weitergegeben werden.

7. CSV für Excel

Mit CSV für Excel wird der aktuell angezeigte Rapport als CSV-Datei exportiert. Enthalten sind Kalenderwoche, Jahr, Mitarbeiter, Tag, Datum, Tätigkeit, Objekt, Einzelstunden, Tagessumme und gesamte Wochenstunden.

Die Datei verwendet eine für deutsche Excel-Versionen geeignete Semikolon-Trennung und kann in Excel geöffnet bzw. importiert werden.

8. Datenschutz

Die App überträgt die eingegebenen Rapportdaten nicht automatisch an einen Server oder eine Cloud. Die Datenhaltung erfolgt lokal im Browser des verwendeten Geräts. Die App enthält keinen eingebauten Firmen- oder Arbeitgebernamen.

Beim normalen Laden einer über GitHub Pages bereitgestellten App entsteht technisch eine Verbindung zum Hosting-Dienst, um die App-Dateien abzurufen. Die von dir eingegebenen Rapportdaten werden durch die App dabei nicht hochgeladen.

Erst wenn du selbst eine CSV-Datei exportierst, druckst, als PDF speicherst oder die Teilen-Funktion verwendest, können Daten das Gerät über den von dir gewählten Weg verlassen.

9. Aktualisierung der App

Nach einer neuen Version kann der Browser kurzfristig noch eine ältere Offline-Version anzeigen. Dann die Seite neu laden. Falls erforderlich, die Home-Bildschirm-Verknüpfung neu öffnen bzw. die alte Website-Zwischenspeicherung des Browsers aktualisieren.

10. Empfohlener Arbeitsablauf

KW/Jahr eintragen → Mitarbeiter eintragen → Tätigkeiten, Objekt und Stunden je Zeile erfassen → Gesamtstunden kontrollieren → Speichern → Vorschau prüfen → CSV/PDF/Druck bei Bedarf ausgeben.
